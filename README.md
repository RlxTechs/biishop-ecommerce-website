# BiiShop E-commerce Website

Site e-commerce responsive pour BiiShop.

## Fonctionnalités

- Catalogue produits dynamique
- Interface responsive mobile, tablette et ordinateur
- Panier avec commande WhatsApp
- Interface admin en Python Flask
- Ajout, modification et suppression de produits
- Upload d'images produits
- Mode clair et mode sombre
- Logo animé
- Design orienté conversion
- Compatible Netlify

## Lancement local

Lancer le site :

.\start_admin.ps1

Site client :

http://127.0.0.1:5050/

Admin :

http://127.0.0.1:5050/admin

## Déploiement

Le site peut être déployé sur Netlify avec un ZIP propre du dossier client.
